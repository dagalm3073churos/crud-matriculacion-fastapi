📚 Sistema de Matriculación - UCE (FastAPI & SQLite)Un sistema de gestión de matriculación universitaria desarrollado con FastAPI y SQLite para la Universidad Central del Ecuador (UCE).Este proyecto implementa una API RESTful completa (CRUD) junto con una base de datos relacional normalizada hasta la Tercera Forma Normal (3FN), cumpliendo con los estándares de diseño relacional, validación de schemas mediante Pydantic e integridad referencial.🛠️ Tecnologías UtilizadasLenguaje: Python 3.10+Framework Web: FastAPIBase de Datos: SQLite 3Validación de Datos: PydanticServidor ASGI: Uvicorn🗄️ Arquitectura y Base de Datos (Normalización 3FN)La base de datos (matriculacion.db) está diseñada bajo la 3FN para eliminar la redundancia de datos y prevenir anomalías de inserción, actualización o borrado.Entidades y Relacionesparalelos: Almacena los paralelos disponibles (ej. 001, 002, 003).materias: Contiene el catálogo de asignaturas del semestre (ej. Base de Datos, Programación 1, Historia de la IA).usuarios: Almacena los datos personales de cada estudiante registrado y se relaciona de manera directa con un paralelo mediante una Llave Foránea (id_paralelo).  ┌───────────────┐          ┌────────────────┐          ┌───────────────┐
  │   PARALELOS   │          │    USUARIOS    │          │   MATERIAS    │
  ├───────────────┤          ├────────────────┤          ├───────────────┤
  │ PK id_paralelo│◄─────────┤ FK id_paralelo │          │ PK id_materia │
  │ nombre_paralelo│         │    id_usuario  │          │ nombre_materia│
  └───────────────┘          │    nombre      │          └───────────────┘
                             │    apellido    │
                             │    cedula      │
                             │    ...         │
                             └────────────────┘
Inicialización Automática: Al ejecutar el script, la base de datos crea automáticamente las tablas y se puebla con datos iniciales (3 paralelos, 6 materias obligatorias y 20 usuarios de prueba).🔌 Rutas de la API (Endpoints)MétodoEndpointDescripciónGET/Comprobación de estado del servidor.GET/paralelosObtiene el listado de todos los paralelos registrados.GET/materiasObtiene las materias disponibles en el sistema.GET/usuariosConsulta el listado de usuarios junto con la información de su paralelo (JOIN).POST/usuariosRegistra un nuevo estudiante (Valida cédula única).PUT/usuarios/{id}Actualiza los datos completos de un usuario por su ID.DELETE/usuarios/{id}Elimina un usuario del sistema mediante su ID.🚀 Instrucciones de Ejecución1. Requisitos PreviosAsegúrate de tener instalado Python 3.8+ en tu sistema.2. Instalación de DependenciasInstala los paquetes necesarios ejecutando:Bashpip install fastapi uvicorn pydantic
3. Iniciar el ServidorEjecuta la aplicación con Uvicorn:Bashuvicorn main:app --reload
(Reemplaza main por el nombre de tu archivo .py si es diferente).4. Documentación Interactiva (Swagger UI)Una vez encendido el servidor, abre tu navegador y dirígete a:Swagger UI: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)ReDoc: [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)Desde la interfaz de Swagger podrás probar directamente cada una de las peticiones HTTP (GET, POST, PUT, DELETE).
